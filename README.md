# NewA1
## FreeLLMAPI on GitHub Codespaces (phone friendly)

This repo can run [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi) in a GitHub Codespace — no PC needed.

1. On your phone browser, open this repo on github.com → **Code** → **Codespaces** → **Create codespace on main**.
2. Wait for setup to finish (first time takes a few minutes).
3. Open the **Ports** tab → port **3001** → open in browser. Finish first-run setup, then add provider keys on the **Keys** page.

Notes: the Codespace sleeps after ~30 minutes idle and only runs while open; free accounts get a limited number of Codespace hours per month.
See [awesome-freellm-apis](https://github.com/open-free-llm-api/awesome-freellm-apis) for where to get free provider keys.
